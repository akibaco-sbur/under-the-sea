# Under the Sea

球面ディスプレイ **FPV130** にプロジェクターで海中を投影する、体験型デジタルアートのUnityプロジェクトです。

## 作品コンセプト

中心となる体験は「えさやり」です。数種類の色の餌を用意し、食べた魚がその餌の色になることを構想しています。自分の行為の結果が魚の色として海の中に残り、主体感や、「別の色をあげたらどうなるか」「別の魚にも食べさせたら」という探索につなげます。

身体入力にはAzure Kinectを使う方針です。座った状態／立った状態での身体インタラクションを検討します。餌をどう選び、どう海へ差し出すかは、今後詰める重要な設計事項です。

泡、自分の影、声で魚が逃げる反応なども追加候補です。これらと上記のえさやり体験は構想であり、実装済み機能を示すものではありません。今回の整備対象は開発基盤・命名・ドキュメントです。

議論の参考資料: [Notion議事メモ（参照専用）](https://app.notion.com/p/403346e30f60802392bcc0f80910bf11)

## 開発

- Unity **6000.3.26f1**（Unity Hubで同じバージョンを用意）
- Universal Render Pipeline **17.3.0**
- Git LFSが必要です。クローン後に `git lfs install` と `git lfs pull` を実行してください。
- ビルド対象シーン: `Assets/Scenes/honban.unity`。`test.unity` は検証用シーンです。
- リポジトリ名は `under-the-sea`、製品表示名は `Under the Sea` です。

Unity Hubからこのフォルダーを開き、パッケージ解決とコンパイルの完了を待ちます。IDE用の `.slnx` / `.csproj` は各環境で生成します。Unity Cloudの既存プロジェクト名やプラットフォーム識別子は、表示名変更に合わせて変更していません。

エージェント操作のセットアップと確認方法は [Unity連携手順](docs/unity-agent-setup.md)、作業規約は [AGENTS.md](AGENTS.md) を参照してください。
