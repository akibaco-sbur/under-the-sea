# 魚のマテリアル色セット

## 新しい設定方法

魚の `StripedFishAnimatedQuadBillboard` にある **餌やり時のマテリアル変更 → 差し替え設定** を使います。

各要素は次の2項目だけです。

- **変更する元マテリアル**：現在その魚に使われているMaterialアセットを指定します。元モデルのSkinnedMeshRendererのMaterialsから割り当てられます。
- **差し替えに使う色セット**：差し替え候補をまとめた `FishMaterialColorSet` アセットを指定します。

番号やNameの入力は不要です。同じ元マテリアルが複数の枠で使われていれば、該当する枠をすべて変更します。目やヒレなど変更しないマテリアルは登録しません。体とヒレに別々のセットを使う場合は2要素登録します。同じ元マテリアルの重複登録はエラーになります。

## 用意済みの原色セット

`Assets/Materials/PrimaryFishColors/PrimaryFishColorSet.asset` に、赤・黄・青・緑・シアン・マゼンタの6色を登録済みです。

まず対象の元マテリアルと、このセットを割り当ててください。Mainの魚生成元にPlay前に設定すると、生成された魚にも引き継がれます。シーンへの割り当ては自動変更していません。

## セットを自分で作る

Projectウィンドウで **Create → Fish → Material Color Set** を選びます。

アセットの **差し替え先のマテリアル** に、必要な候補をまとめて登録します。魚ごと・部位ごとにセットや候補数を変えられます。セットの用途はアセット名で識別します。候補ごとのName欄はありません。

## 餌との対応

餌の色番号ではなく実際のRGB色を渡し、各色セット内のマテリアルのBase Color（なければColor）との差が最小の候補を選びます。配列の並び順を餌と揃える必要はありません。

セットに同じ色があればその色になります。ない場合はセット内の最も近い色です。例えば原色セットではオレンジ色の餌は赤、紫色の餌はマゼンタに近いものとして選ばれます。同距離なら先に登録されたものを使います。テクスチャ画像のピクセル色は解析しません。候補マテリアルのBase Colorを色の判定に使用します。

魚は餌に接近し、食べ終わったタイミングで各対象を変更します。毎回、元マテリアルの構成を基準に対象を探すため、既に色が変わっている魚にも再度使えます。指定していない枠は元のマテリアルになります。

## 確認

Play中はコンポーネントのInspectorに、最初の色セット内のマテリアル名のプレビューボタンが表示されます。押すとその色を基準に差し替えを確認できます。餌を食べる動作の試験は従来のキーボード操作を使います。

Inspectorの **以前の設定（互換用）** は旧Material Variantsの設定です。旧Nameは候補を識別する表示名だけで、色の判定には使いません。旧設定は差し替え設定が空の場合のみ利用します。以前のシーン設定を消す移行処理は行っていません。
