# 前進・餌やりの前に体を視線へ向ける

前進と餌やりは、DiverViewのカメラが実際に向いている水平の方向へダイバーの体を向け、上下視点を水平へ戻した後に開始します。首の左右角度を体へ徐々に引き継ぐため、向き直り中に視点が元の正面へ戻ったり、体の回転と二重に回ったりすることを防ぎます。

- 前進：完了するまで速度を0に保ち、完了後に既存の加速処理を始めます。その後は体の正面へ進み、ビルボード用カメラの向きを移動方向に使いません。
- 餌やり：移動を止めて向き直り、完了後に台・餌・腕の追従・魚の呼び寄せを始めます。
- 既に左右正面を向いていれば、不要な回転待ち時間は設けません。ただし上下を向いている場合は水平へ戻るまで待ちます。
- 向き直り時間はDiverViewControllerのBody Turn Duration、上下の戻りはView Smooth Timeを使います。
- 向き直り中の新しい視点指示・後ろ向き・無効化等は、待機していた動作を取り消します。Stopは前進待機を、Backspaceはキーボード試験の餌やり待機も取り消します。

## Rootの扱い

Mainの保存設定では、bodyRoot/movementRootがアニメーション用Rootボーン、movementReferenceがBillboard Cameraでした。実行時、ダイバーモデル内の子ボーンが体の回転・移動先として指定されている場合は、コンポーネントを持つダイバー全体のTransformへ統一します。Rootボーンは既存の速度連動の傾きに使い続けます。シーンYAMLは変更していません。

モデルのインポート軸に依存しないように、初期Faceボーンの向きから体の正面を記録します。餌・腕・魚の基準カメラも実際のDiverViewカメラを使用します。

## 確認

左右45/90度・前後180度の角度引き継ぎ、向き直り途中の開始禁止、上下の水平化待ち、既に正面の場合の待機省略など、模擬テスト14項目成功。Unity参照DLLによるプロジェクトC#コンパイル成功。

Unityは起動・操作していません。実モデルの姿勢、移動、カメラの見え方はEditor内で未確認です。

## 前進中の左右操作

前進中に左右を指示すると、後ろを向く操作と同じ体全体の滑らかな旋回を使います。移動方向は体の向きを毎フレーム読むため、旋回に追従して進路が曲がります。停止中の左右操作は従来どおり首・視線だけを変更します。上下の視点操作による高度変更は行いません。音声と開発用キーは同じ処理を使用します。
