# 撤退・離席と航行記録

Mainでは認識と起動演出が終わってからダイバー本体の位置を記録します。「撤退」「撤退して」「撤退します」、開発用キー操作がONならRキーでも終了します。餌やり中も終了できます。

操作と餌やりを停止し、Voskは既存の終了処理で停止します。約2.4秒のシャットダウン後に、黒背景の中にSeaBed範囲の白い領域を置き、水色の軌跡を約8秒で描画します。白い領域には距離目盛り付きのグリッドを表示します。目盛りはSeaBedの西端・南端からの距離で、1マスの距離と全体の縦横距離も表示します。北（ワールド＋Z）が上です。枠はSeaBed全体のワールドXZ範囲で固定し、縦横比を保ちます。範囲外の線は枠で切り取ります。SPACEで再再生できます。画像ファイルは保存しません。次の体験はPlayを終了して再実行してください。

DiverRetreatの「軌跡の範囲」を省略すると、同じシーンのSeabed（大文字小文字を区別しない）を検索します。子のRenderer、Terrain、必要ならColliderから全体の範囲を取得します。今回のMainにはSeabedが存在することをソースから確認しています。取得できない場合は警告し、軌跡の範囲を代わりに使用します。撮影カメラ、RenderTexture、霧設定の変更は使用しません。

記録は0.2秒間隔で確認し、原則0.25m以上の移動で追加します。上限4,096点で間引き、出発点と撤退地点を保持します。保存ファイルは作らず、Play終了で破棄します。HUDの累計移動距離と同じ記録を使います。

実機では、最初に認識した人を1.5秒間見失うか、座った状態より胸が300mm以上上がった状態が1.5秒続くと、自動で同じ終了処理へ進みます。手だけの認識失敗は終了条件ではありません。別人へのすり替わりや古いフレームも認識喪失として扱います。途中で元の人の上半身が復帰すれば猶予時間をリセットします。

PlayerRecognitionScreenのKinectStartupControllerで「離席・認識喪失で終了するまでの秒数」「立ち上がり判定の胸の上昇量（mm）」を調整できます。キーボード試験で開始した体験には自動離席終了を適用しません。

検証：Unity参照DLLによるC#コンパイル、離席判定15項目、既存の位置記録11項目・向き直り14項目の独立テスト成功。Unityは起動していません。実際の表示・操舵・実機の離席判定は未確認です。
