# 餌へ前方から接近する

Mainの餌やりではDiverViewのカメラを基準に、まず餌より前側にいる魚を全てのSummonFishから探します。候補があれば近い1匹を選びます。前側に有効な候補がない場合だけ、後ろ側の魚を選びます。

後ろ側から来る魚は、現在の左右位置に応じた側へ移動し、ダイバーの横を通って前方へ進み、餌の正面にある地点から餌へ向かいます。最初から前側にいる魚も正面の地点を経由し、最後はダイバーへ向かって接近します。既存の岩回避処理は各移動に適用します。

食事成立には、正面への回り込みが完了したこと、口が餌の前側にあること、ダイバーへ向かう方向に泳いでいること、口が接触範囲内にあることを要求します。その状態を既存の食事時間だけ保つと、その魚の色が変わります。後方から接触しただけでは成立しません。手や視点の変化で後ろ側になった場合は回り込みへ戻します。餌がダイバーの後ろへ移った場合は接近を中止します。

SummonFishのFeeding欄で調整できます。

- **餌の前方で待つ距離**：既定1.2m。最後に餌へ向かう前の地点。
- **ダイバーの横を通る距離**：既定1.2m。後ろの魚が横を通る際の距離。
- **回り込み地点の到着距離**：既定0.35m。経由地点への到着判定。

前後方向にはカメラの向きを水平面へ投影した方向を使います。上下を見るだけで回り込み方向が傾くことはありません。

Unity参照DLLによるC#コンパイルと、候補優先度・前後判定・回り込み経由点・食事条件の模擬テスト16項目が成功しました。Unityは起動・操作していません。実際の魚の軌道や回り込み距離はEditor内で未確認です。
