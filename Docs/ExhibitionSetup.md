# USBマイクと展示前の確認

## マイク

VoskOfflineVoiceCommandsの「入力マイク名」はWUP-021-0を既定値にしました。完全一致を優先し、一意な部分一致にも対応します。「マイク (WUP-021-0)」のような名前も選択できます。見つからない・複数一致の場合は内蔵マイクへ切り替えず、Voskモデルの新規読み込み前に停止します。

コンポーネントのメニュー「利用可能マイクをConsoleに表示」でUnity側の名称を確認できます。Inspectorの「検出マイク一覧」「選択されたマイク」、Consoleの[Vosk] Selected microphoneを確認してください。Unity側の名前にWUP-021-0が含まれなければ、一覧の完全な名前を「入力マイク名」へ入力してPlayを再実行します。変更を本番に残すにはPlay前に設定してシーンを保存してください。

USB機器の対応サンプルレートを確認して取得レートを調整します。Voskへは既存の変換で16kHzモノラルを渡します。マイクが停止・切断した場合は音声処理を停止し、別機器へ自動変更しません。再接続と設定変更はPlayを再実行してください。実機のデバイス一覧と録音はこの作業では確認していません。

## 現在の保存済みMainで要確認の設定

- Keyboard Feeding Test ModeがONです。本番ではOFF。ONのままだとKinect入力を迂回します。
- 開発用キー操作がONです。スタッフ試験後、本番で不要ならOFF。
- Palm Up Required For FeedingがOFFです。手のひら条件を使う本番仕様ならONにして、現地の手のひら上向き判定を確認してください。現地診断結果がまだないため、軸・閾値は未調整です。
- Run In BackgroundがOFFです。スタッフのウィンドウ操作などでフォーカスが外れても継続したい場合はONにしてください。
- Windows側でもWUP-021-0の入力レベルとマイク使用許可を確認します。Unityでは起動後の「音声操作 OK」と実際のコマンド動作を確認してください。

Voskコンポーネントのメニュー「本番設定をConsoleで確認」でも、現在の試験設定とRuntime配置を確認できます。自動で設定を書き換える機能ではありません。

## 本番PC・投影・配布

- この作業フォルダでは.Local/AzureKinect/Runtimeのk4a.dll・k4abt.dllを確認できませんでした。本番PCには既存のTools/SetupAzureKinect.ps1とAzureKinectSandbox.mdに従ってRuntime一式を配置してください。DLLだけでなく依存DLLとdnn_model_2_0_lite_op11.onnxも必要です。
- Windows x64が必要です。exeで配布する場合、.Local/AzureKinect/Runtimeはexeと同じフォルダを基準に置きます。通常のUnityビルドではこの.Localフォルダは自動同梱されません。
- StreamingAssets/vosk-model-ja-0.22.zipはこの作業フォルダに存在します。配布先にも必要です。起動時のモデル準備と音声準備が終わったことを確認します。
- SDKのCPU/DirectMLは本番PCで実機テストしてください。現在の既定はDirectMLです。診断CSVと同名JSONから処理遅延・認識の欠落を確認して調整します。
- 実際のプロジェクター解像度・ディスプレイ出力でUIを調整し、ProjectionLayout.jsonを保存します。設定はPCごとのpersistentDataPathにあるため、本番PCで再調整するか同じ設定ファイルを配置してください。
- 音の出力先と音量、InWater・排気・受付・給餌・境界ノイズ・ポップアップ音を確認します。Resources/DiverAudioの6音源は配置済みです。
- 診断記録を終了し、診断画面と本番で不要なF7/F9/F10キーを無効にします。F8の診断専用開始で起動した試験を、そのまま通常運用にしないでください。
- ボーダー停止後の自動撤退時間、離席終了の秒数・胸の上昇量は、現地の椅子・センサー配置で確認します。
