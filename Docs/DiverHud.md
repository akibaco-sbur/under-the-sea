# ダイバーのヘルメットHUD

MainシーンのPlay時に `DiverHelmetHud` を自動生成します。認識画面の後に[ロボット視界の起動演出](RobotVisionStartup.md)を再生し、HUDを順に表示します。既に同じシーンに `DiverHudController` があれば二重生成しません。シーンファイルの編集・追加設定は不要です。

## 表示

- 左上：音声の準備中・使用可能・利用できない状態。Voskの実際の状態を読み取ります。
- 右上：前進開始・前進中・減速中・停止中と実際の移動速度。
- 上中央：DiverViewカメラの水平方位。ワールド＋Z=N、＋X=Eです。実際の地磁気の方位ではありません。
- 下中央：餌やり中だけ、操作案内・段階ごとの進捗・餌色を表示します。
- 通常時の下部：短い音声コマンド案内。
- キーボード試験時の最下部：F/WASD/EQ/Shift/Backspace/Rのキー案内。

中央の視界は空けています。ロボットらしさを強める明るいシアンの外周フレーム、左右の目盛、小さな光学ブラケットを追加しました。腕の追跡状態、視線方向（正面・右・右上・上・左上・左・左下・下・右下など）、操作開始からの累計移動距離、速度バー、稼働時間も表示します。視線方向は体の正面を基準に判定します。移動距離は撤退時の軌跡記録と共有し、往復した距離も加算します。首やカメラの揺れは加算しません。全面の常時走査線や点滅は使用していません。

## 調整

Play中の `DiverHelmetHud > DiverHudController` で **HUDを表示**、**表示の濃さ** を変更できます。Play中の設定はPlay終了時に戻ります。

設定を保存したい場合は、Play前にMainシーンの空GameObjectなどへ `DiverHudController` を1つ追加し、設定してシーンを保存してください。自動生成はそのコンポーネントを優先します。

日本語を表示できる使用フォントを指定できます。省略時はWindowsのYu Gothic UI/Yu Gothic/Meiryo等を探して動的フォントを作ります。日本語フォントのない環境では別途指定してください。解像度に応じてCanvasScalerで拡縮し、Screen.safeAreaへ収めます。

HUDにはボタンや入力を遮る領域はありません。既存のGameビューのキー操作を妨げません。HUDを表示中は従来の餌やりテスト用OnGUI表示を抑制し、HUD非表示・無効化時に元の表示へ戻します。

## 読み取り専用の連携

HUDがVoskモデルやKinectを新しく起動することはありません。既存のコンポーネントの公開状態を読むだけです。Voskが停止・無効化されていても移動・餌やりの表示は独立して動きます。文字情報は10Hz、方位の目盛は毎フレーム更新します。

## 検証

Unity参照DLLを使ったプロジェクトC#コンパイル成功。方位の周回、上下を向いたときの保持、前進・減速・停止の表示など13項目の独立テスト成功。

Unityは起動・操作していません。レイアウト確認用の静止画はUnityのスクリーンショットではありません。実際のGameビューでの表示、フォント、海中背景に重ねたときの読みやすさは未確認です。
