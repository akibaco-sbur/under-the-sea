# 集まった魚が早い者勝ちで餌を食べる

Mainでは次の流れになります。

1. 餌やりモードに入ると、同じシーンの各SummonFishを横断して近い魚を最大4匹選びます。今回の餌色に有効なマテリアル変更設定がある魚が対象です。
2. カメラ前方2.8m付近へ泳いで集まり、約0.9mの範囲で、それぞれ異なる目標位置を選んで泳ぎます。魚を瞬間移動させません。
3. 餌を掬って前へ差し出すと、集まった魚が一斉に餌へ向かいます。Mainでは従来の5秒保持を待ちません。単に持ち上げただけでは反応しません。
4. 前側から接近し、最初に食事条件を満たした1匹だけが餌色に対応するマテリアルへ変わります。その時点で固形の餌を非表示にし、全参加魚の予約と追跡を解除します。
5. 食べられなかった魚は色を変えず、通常の遊泳へ戻ります。既存の餌の拡散表示とモード終了処理は維持します。

後ろ側の魚は従来どおりダイバーの横を通って前へ回り込みます。背後からの接触では食べられません。岩を避ける既存処理も使います。

手を引っ込めたり追跡が途切れた場合、競争を止めて前方での待機遊泳に戻します。再度差し出せば競争を再開します。Backspace、コンポーネント無効化、シーン終了、餌の消失では集まり自体を解除します。

## 調整

`DiverFeedingFoodController > 餌やり前の魚の集まり` で調整できます。

- 呼び寄せる魚の数：4匹
- カメラ前方の距離：2.8m
- 自由に泳ぐ範囲：0.9m
- 近い魚を探す範囲：60m

設定をPlay後も保存したい場合は、Play前にVoiceCommandsへDiverFeedingFoodControllerを追加して設定してください。既にある場合は重ねて追加しません。近くに条件を満たす魚がなければ、餌は消さず、1秒間隔で候補を探します。Consoleで色セットと探索範囲を確認できます。

## 検証

同時到着時の1匹限定、キャンセル後の遅延到着、不正な色設定、差し出し直後の反応、手の引き戻し・追跡中断等、模擬テスト17項目が成功しました。ScoopFeedingLogicの既存の試作向け5秒待機APIは維持し、Mainだけ新しい差し出し状態を使います。Unity参照DLLによるプロジェクトC#コンパイル成功。

Unityは起動・操作していません。実際の魚の群れ・軌道・速度・実機での差し出し判定は未確認です。
