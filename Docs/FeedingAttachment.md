# 餌やり中の視点固定と手のひらへの追従

従来は、モデルの腕にはカメラ相対の手の位置補正を加えていた一方、餌と接触判定は補正前のKinect／キー入力座標を使用していました。向きによって補正方向が変わるため、モデルの手と餌が一致しませんでした。

Mainでは腕のApplyPoseAtPalmが成功した後のPalmCenterPositionを接触・判定球・餌の追従へ共通して渡します。持ち上げ後の餌は手の接触用Transformへ付け替え、世界座標の大きさを維持します。台へ戻す・食べられる・キャンセルする際は台へ戻します。手のひらの少し上（0.045m）に餌を表示する仕様と、腕の補正値・スケール設定は維持します。

餌やり開始時には移動を止め、DiverViewControllerの餌やり操作ロックを取得してから自動の体の向き直りを行います。準備・餌を掬う・差し出す・魚が食べた後の演出中は上下左右・後ろ向き・視点リセット・前進開始を受け付けません。音声・開発用キーは同じ公開メソッドを使用するため両方に適用します。停止・撤退は可能です。

終了・キャンセル・途中失敗・コンポーネント無効化でロックを解除します。連続した餌やり指示は進行中の餌やりを初期化しません。キー試験の水色マーカーもモデルの手のひらと共通の接触位置になります。

検証：Unity参照DLLによるC#コンパイル、現行のScoopFeedingLogicを使った向き0/45/90/-90/180度での接触・持ち上げ・差し出し・戻しの20項目の独立テスト。Unityを起動していないため、実際の親子付け替え、手と餌の表示、音声・キーの操作ロック、Kinect実機の確認は未実施です。
