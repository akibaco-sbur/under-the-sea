# Fish Feeding Sandbox

`Assets/Scenes/Sandbox.unity` で、仮の魚18匹が餌へ集まる動きを検証します。Mainおよびビルド対象は変更しません。追加パッケージ、物理演算、Kinect SDKは不要です。

## 操作

1. Sandboxを開き、`FishFeedingDemo` がアクティブ、`AzureKinectDemo` と `RenderingSamples` が非アクティブの状態でPlayします。
2. Game Viewの水面をクリックすると、その場所へオレンジ色の `Food` が移動します。餌が非表示の場合もクリックで再表示します。
3. Fキーで餌の表示を切り替えます。餌がない間も魚は泳ぎ続けます。
4. Play中、Inspectorから `FishFeedingDemo/Food` のTransformを動かしても追従します。魚はデモのローカルXZ面で泳ぐため、餌の高さは追従方向に使いません。クリック移動は範囲の内側に制限します。

骨格を試す場合はPlayを止め、`FishFeedingDemo` を非アクティブ、`AzureKinectDemo` をアクティブにします。各グループは専用Camera・Audio Listenerを持ちます。同時には有効にせず、[Azure Kinectの手順](AzureKinectSandbox.md)に従ってください。魚だけのPlayでは骨格コンポーネントもSDKの初期化も起動しません。

## 動きと調整

`Assets/Scripts/FishFeedingDemo.cs` がPlay開始時に魚のGameObject、楕円体の胴、目、三角形の尾と胸びれを生成します。停止時には生成したMesh・Materialを破棄します。

- 遠くの餌には加速しながら旋回し、近くでは減速して個体ごとの半径・向きで周回します。餌を移すと、そのフレーム以後の実Updateで新しい位置へ向きを変えます。
- 速度、応答、位相、大きさに個体差があります。近隣との距離から進路を変え、柔らかい境界で泳ぐ範囲を保ちます。Colliderによる接触防止ではないため、すれ違い時の重なりはあり得ます。
- 餌が非アクティブ、または `Food` が未指定の場合は、各個体の滑らかな蛇行と境界への反応で遊泳します。
- 速度に応じた尾振り、旋回時の傾き、個体ごとの上下動を加えています。尾の位相は時間を積分し、速度変化で飛ばないようにしています。
- 向きと速度の変化に上限を設け、長いフレームは最大0.08秒・1/60秒以下の小刻みな更新に分けます。大きな処理落ちでは追いつくための瞬間移動を避け、遊泳が遅くなります。

Inspectorの主な値:

| 項目 | 既定値 | 用途 |
| --- | --- | --- |
| Fish Count | 18 | 生成数（2〜40） |
| Half Extents | X=8、Z=5 | 遊泳範囲の半幅 |
| Cruise Speed | 1.25 | 個体差を掛ける基準速度 |
| Turn Degrees Per Second | 95 | 応答係数を掛ける旋回上限 |
| Acceleration | 1.2 | 応答係数を掛ける速度変化の上限 |
| Separation Distance | 0.85 | 近隣の魚を避ける距離 |
| Food / Interaction Camera | シーン内の参照 | 追従先／クリックの投影Camera |

生成数や個体差の基準値はPlay開始時に読み込みます。動作の比較は停止して値を変えてから再Playしてください。魚の色は初期の見分け用で固定です。餌の消費、色変化、Kinect入力との接続、FPV130用の投影はこのデモに含めません。

## 検証（2026-10-24）

- Unity 6000.3.26f1で実コンパイル完了、Error 0・Warning 0。最終PlayもConsoleとEditor側の件数でError 0・Warning 0。
- 18匹のGame Viewを15 FPSで450フレーム連続収録。動画30.000秒、実収録30.03秒。ゲーム時間0.929→30.864秒、フレーム82→3851と進行しました。静止画の切替ではありません。
- 初期接近では餌までの平均距離6.264→1.824m、3m以内の魚5→18匹。餌を `(5, 0, 2)` から `(-4.5, 0, -1)` へ移すと、新しい餌座標から計算した平均距離10.340→1.937m、3m以内の魚0→17匹へ変化しました。
- 餌を非アクティブにした後も速度、座標、尾の角度が変化し、遊泳を継続しました。近傍での減速・周回、尾振りと個体ごとの向きの違いをGame Viewで確認しました。
- 一時的なInput Systemデバイスで入力イベントを送り、Fキーで餌が非アクティブになること、非表示の餌がクリックで再表示され、投影先 `(-2, 0, 0)` へ移動することを実Update経由で確認しました。検証デバイスは除去しています。
- 収録中の座標は有限値。15 FPSの観測差分では旋回最大120.71度/秒、速度変化最大1.525m/秒²。境界は柔らかいため半幅を一時的に越えます（観測最大絶対座標X=8.002、Z=6.218m）。
- 魚デモ中はCamera 1、Collider 0、アクティブなKinectコンポーネント0、`k4a.dll` / `k4abt.dll` のロード0。骨格用Camera・関連コンポーネントの設定と元のSandboxオブジェクトは保持しています。Main・ビルド設定・SandboxのGUIDは変更なし。

実機Kinectへの切替後の再追跡、Standaloneビルド、FPV130への投影は今回未検証です。動画と画像はPRに添付し、ローカルの録画・計測ログはコミットしません。
