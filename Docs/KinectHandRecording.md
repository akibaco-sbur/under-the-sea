# Kinect 手のベンチマーク録画

Azure Kinect の RGB と depth を、手の開閉の比較用に短く記録する実験用スクリプトです。保存した記録は `Tools/ReplayHandBenchmark.py` で現在の認識ワーカーに入力できます。[オフライン評価](HandRecognitionBenchmark.md)を参照してください。正解ラベルの専用確認画面は未実装です。

## 準備と操作

1. [Azure Kinect のセットアップ](AzureKinectSandbox.md)を済ませ、Kinect の電源と USB を接続します。Windows x64 と Python が必要です。
2. Unity が Kinect を使用している場合は Play を停止します。
3. プロジェクトのルートから `python Tools/KinectHandRecorder.py` を実行します。
4. 画面の「録画開始」を押します。各動作の前に10秒の準備時間があり、指示を読んで手の姿勢を作れます。画面が「計測中」に変わったら、表示された動作を5秒間続けます。8動作で全体は約2分です。録画中のキーボード操作は不要です。
5. 録画が終わると、保存と再生検証を行います。完了と表示されるまで待ってください。

グーの回転と胸からの距離を比較する追加録画には、`python Tools/KinectHandRecorder.py --fist-distance` を使います。右手をグーに保ち、胴体の外側と、胸の中央の前で「カメラ側（腕を伸ばす）」「中間（肘を軽く曲げる）」「胸のすぐ前」の各位置について、止めた状態と回す動作をそれぞれ撮ります。距離は姿勢による目安であり、実測距離ではありません。8動作・約2分で、準備は各10秒、計測は各5秒です。

人が動く前の確認には `python Tools/KinectHandRecorder.py --smoke` を使えます。準備1秒・計測2秒で録画し、RGB・depth の両方と保存されたキャリブレーションを読み戻して検証します。

## 記録内容とラベル

各録画は Git 対象外の `.Local/HandBenchmark/take-.../` に新規作成されます。同名の録画を上書きしません。

- `Kinect.mkv`: 720p RGB、640×576 depth、時刻、デバイスのキャリブレーション。指定フレームレートは15fpsです。
- `Frames.csv`: 各フレームの色・depth のデバイス時刻、経過時間、指示の番号、条件、準備または計測の区間、指示上の仮ラベル、確認済みラベル欄。
- `Session.json`: 録画条件、フレーム数、指示とその時間。録画を開き直して検証できた場合に作られます。

指示は「前で止める」「胸の前に重ねる」「ゆっくり回す」「左手で半分隠す」のそれぞれで、パーとグーを試します。準備中の `stage` は `PREPARE`、計測中は `PROBE` で、準備中の `suggestedLabel` は空です。計測中の `suggestedLabel` は**画面の指示**であり、実際の手の状態を保証する正解ラベルではありません。画像取得と画面描画の時間差もあるので、評価に使う前に映像を見て `verifiedLabel` を確認し、曖昧な区間を除外してください。遮蔽で映像から手の形が確認できない場合は、撮影時の状況も確認し、確証のないラベルは付けません。

見えにくい場面を含む指示区間全体を評価する場合は、目視で確定できたフレームだけの評価と分けて、`--provisional-probe` で全区間を分母にします。認識できなかった・見えづらかったという理由で難しいフレームを都合よく除外しません。指示ラベルを確定正解と呼ばない点にも注意してください。

中断やエラー時は `Invalid.json` が作られ、`Session.json` は作られません。途中までのデータは原因確認のため残します。RGB 映像や記録はローカルに保存し、自動送信しません。
