# Windows時刻による体験時間と航行記録画面

体験時間はDateTimeOffset.Nowで取得したWindowsの開始日時と終了日時の差から計算します。UnityのTime.deltaTime、timeScale、フレーム数を体験時間に使いません。

開始はKinect認識後のロボット起動演出が完了し、操作可能になるタイミングです。終了は「撤退」・ボーダー停止後の自動撤退・離席終了の要求を受け付けたタイミングです。シャットダウン演出や軌跡再生は含めません。HUDの体験時間も同じ記録を使い、終了後は値を固定します。開始・終了はWindowsのローカル日時で結果画面とログに表示します。日付またぎやタイムゾーンのオフセットを含めて差を計算し、負の差は0にします。

結果画面は暗い紺色の背景、シアンの外周フレーム、左右4つの情報パネル、中央の白いSeaBedグリッドと発光する水色の軌跡です。開始日時・終了日時・体験時間・移動距離・記録点数・SeaBed範囲・1マスの距離を表示し、下部のバーで再生進捗を示します。Spaceで再再生できます。ファイル保存や追加カメラは使用しません。

位置記録と体験時間は同じ体験期間に対応します。起動演出で操作が解禁されると時計を開始し、その後の更新で位置記録を開始します。終了時の時計を先に固定してから、音声などの終了処理に進みます。境界停止の15秒タイマーなど、別の待ち時間の設定は変更しません。

検証：Unity参照DLLによるC#コンパイルと、開始・終了の固定、日付またぎ、オフセット、表示書式など12項目の独立テストを実施。Unityは起動しておらず、Gameビューでの表示・配置は未確認です。
