# 投影UI・給餌地点・Kinect現地テスト

## 投影範囲の調整

MainでPlayするとProjectionUiSettingsを自動生成します。DiverProjectionLayoutの「UI表示範囲」を調整してください。X/Yは画面の左下を0とする0～1の割合、Width/Heightは表示範囲の幅と高さです。「調整枠を表示」で確認し、「UI全体倍率」で全体を拡大縮小できます。初期値は添付画像を参考に中央より少し左の範囲へ寄せた暫定値です。実際の投影面を計測した値ではありません。

HUD、認識画面、終了画面、ポップアップを同じ範囲へ縦横比を保って配置します。画面ノイズ・黒／白の背景・カメラの投影自体は変更しません。倍率1が範囲に収める基準です。拡大する場合は実際の表示を見ながら調整してください。

調整後にコンポーネント右上のメニューから「投影UI設定を保存」を実行すると、ConsoleにProjectionLayout.jsonの保存先を表示します。次回起動時に読み込みます。このJSONも結果と一緒に共有してください。

## 軌跡の餌やり地点

魚が実際に餌を食べた瞬間のダイバー位置を、餌色付きのF01・F02…として記録します。待機モードに入っただけでは記録しません。終了画面ではSeaBedの枠に沿って位置を表示し、給餌成功回数も表示します。最大128地点で、軌跡の間引きでは消えません。今回のPlay中だけ保持します。

## 現地でのテスト手順

1. Azure Kinectと本番のPC・椅子・マイク位置を使います。VoskOfflineVoiceCommandsのKeyboard Feeding Test ModeはOFFにしてください。ONだとKinectの実入力を検証できません。開発用キー操作のON/OFFは別設定です。
2. GameビューをクリックしてF9を押すと、診断画面を表示してCSV記録を開始します。F7で診断画面だけを隠せます。記録は継続します。
3. 数字1を押し、着席して正面を向いたまま20秒ほど待ちます。普段どおり認識が通るかも確認してください。周りを別の人が通った場合は、その時刻と状況もメモしてください。
4. 着席認識が通らず先へ進めない場合だけ、記録中にF8を押してください。診断専用で認識を迂回しますが、Kinectの取得は継続します。通常のKeyboard Feeding Test ModeによるEnterスキップとは異なります。診断迂回した体験は離席による自動終了を行わず、JSONにもその使用を記録します。次回Playでは通常に戻ります。
5. 数字2で手のひらを上にして10秒、数字3で下にして10秒、数字4で餌を掬う動作を3回、数字5で差し出す動作を3回試します。可能なら手の位置・センサーからの距離も変え、うまくいかない姿勢で数秒止めてください。
6. 数字6で立ち上がる・画角から外れる動作を試します。最後にF10で記録を保存終了します。Consoleの[KinectTest] Saved CSV + JSONに保存先を表示します。

保存先はUnityのpersistentDataPath内のKinectDiagnosticsフォルダです。CSVと同名のJSONをセットで共有してください。加えて、センサーと椅子の距離、センサーの高さ・向き、座った人の頭から手までの見え方、どの段階で失敗したかを文章で添えてください。

## 何を確認するか

- Bodiesが2以上で開始できない：複数人条件の影響。
- Ageが増える・同じframeが続く：処理遅延やフレーム停止。
- 頭・肩・胸のconfidenceが0/1：上半身の遮蔽や認識品質。通常の開始判定は2以上を要求します。
- ArmがFalse：腕の関節の認識不良。Estimatedは前腕からの推定使用を示します。
- 手のひらを上にしているのにPalm upがFalse：Palm dot・各軸のup dot・手のQuaternion・注釈付きの姿勢を比較して補正軸と閾値を決めます。
- ContactがFalseのまま：モデルの手のひらと餌の距離、補正値を確認します。接触後に失敗する場合はStateや姿勢の連続性を調べます。

CSVにはWindows日時、姿勢の注釈、骨格人数・ID・鮮度、部位ごとの信頼度・座標・回転、認識進捗、腕・手のひら・餌やり状態、カメラ角度を記録します。未選択の場合だけ診断表示用に最も近い候補の関節を表示し、実際の選択IDとは区別します。全候補の胸の位置も記録します。診断が実際の対象者選択を変更することはありません。映像・Depth画像・音声は保存しません。

1記録は10Hz・最大10分・6,000行・8MiB、1回のPlayで最大4記録です。停止・無効化でファイルを閉じます。Kinectを重複起動したり、モデルを再読込したりしません。今回、認識の閾値を推測で変更していません。返却データから着席の対象範囲、信頼度と許容欠落時間、手のひら軸と閾値を調整します。

Unityは起動していません。C#コンパイルと記録・表示倍率・CSV制限の独立テストで確認し、実機・投影の見え方は未確認です。
