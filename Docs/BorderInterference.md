# 境界の警戒ストライプとロボット視界の干渉

境界壁は黄色と暗色の斜めストライプに変更しました。遠方では薄く、近づくと不透明になる従来の距離表現と、範囲外へ出さない処理は維持します。

壁から150m以内でノイズが始まり、20m以内で最大になります。確認用に境界までの距離も表示します。開始距離と最大になる距離はDiverHudControllerのInspectorで調整可能です。画面に横方向に伸びるブラウン管風のノイズ・横帯が入り、音声・移動・方位・補助計器の表示位置がわずかにずれます。実際の移動速度、カメラ角度、方位の値や操作処理は変更しません。

さらに近づくと、灰色の背景と紺色タイトルバーの古いWindows風の警告窓を順に重ねます。最大15枚を初期化時に作り、以降は再利用します。「OK」「×」は演出用で、クリック操作は不要です。全要素は入力を遮らず、離れると窓とノイズが消え、計器は元の位置へ戻ります。起動前・起動演出・撤退演出・軌跡画面には出しません。

DiverHudControllerの「境界付近のノイズ演出」でON/OFF、「境界ノイズの強さ」で程度を調整できます。画面全体を明滅させる表現やカメラの揺れは追加していません。

専用の画面ノイズShaderはAssets/Resources/Shaders/DiverBorderNoise.shaderです。追加カメラ、RenderTexture、録画、画像ファイルの生成は行いません。ポップアップは無制限に増殖せず、生成したMaterialは終了時に破棄します。

検証：C#の参照DLLコンパイルと干渉状態18項目の独立テストを実施。Unityは起動しておらず、両Shaderのコンパイル・実際の見え方・解像度別の配置は未確認です。


ノイズとポップアップの発生間隔はランダムに変え、固定周期を使いません。静かな間と強いノイズが不規則に入り、窓の出現位置もその都度変えます。窓は15枚の上限内で再利用します。
