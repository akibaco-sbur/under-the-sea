# Kinect 手の開閉テスト

`Assets/Scenes/Sandbox/KinectTest.unity` は、Azure Kinect の右手の開閉を単体で調べるためのシーンです。餌や魚の処理には接続していません。

## 操作

1. [Azure Kinect のセットアップ](AzureKinectSandbox.md)に従い、SDK と Kinect を用意します。
2. `KinectTest.unity` を開いて Play し、Kinect の前で右手を見せます。キーボード操作は不要です。
3. 開く・握る・手を動かす操作を行い、手の画像、状態、数値を確認します。開始直後の約 0.4 秒は手が開いていると仮定し、基準値を作ります。

左は全体の depth 画像、中央は右手周辺の拡大図です。水色は面積スコアの計算に使った画素です。体として認識された画素のうち、手を中心とした範囲と奥行きの条件に合う画素を表示します。手の奥行きや画像の端などの条件が合わない場合は `UNKNOWN` になります。RGB 映像は取得せず、depth 画像はメモリ内で表示し、記録しません。

右側は `OPEN / FREE`、`CLOSED / GRAB`、`UNKNOWN` と判定値です。灰色が OPEN、緑が CLOSED、暗い灰色が UNKNOWN です。`Weighted area` は生のスコア、`Filtered area` は平滑化した値、`Open baseline` はパーと仮定した基準、`Area ratio` は平滑化値を基準で割った割合です。`Selected pixels` と `Tip-side pixels` はそれぞれ採用した画素数と手首から遠い側の画素数です。

画素数は奥行きによる大きさの変化を補正し、手首から遠い側を重く扱います。基準に対して 88% 未満が約 0.2 秒続くと CLOSED、96% を超える状態が約 0.2 秒続くと OPEN になります。移動速度が 0.35 m/s を超える間は状態を維持し、OPEN 中は基準も更新します。画面には現在の判定理由と手の距離・速度も表示します。

## 制約

Azure Kinect の標準 API による手の開閉状態ではなく、奥行き画像からの実験的な面積推定です。手の向き、重なり、距離、見切れや開始時の姿勢で誤判定します。移動中の基準更新によって、手の形が変わっても基準が追従してしまう可能性があります。実機では表示・数値の更新は確認できましたが、開閉の誤判定が残っています。精度改善や餌やりとの統合は別途検討します。
