# SeaBedのワールドボーダー

MainでPlayするとSeaBedWorldBorderを自動生成します。軌跡画面と同じSeaBed全体のワールドXZ範囲を使い、外周4面に黄色と暗色の斜めストライプの境界壁を表示します。

- 遠方（既定50m以上）：濃さ約4.5%で薄く表示。
- 接近中：徐々に濃く表示。5m以内では不透明になり、壁の向こう側を隠します。
- 壁を斜めの警戒ストライプで示します。150m以内で画面と計器にノイズが発生し、古いWindows風の警告窓が最大15枚まで重なります。離れると消えます。詳細はBorderInterference.mdを参照してください。
- 端の0.8m内側を移動の限界にします。既存の自動ブレーキ・黄色警告を使用し、最大移動量も限界までに制限します。
- 方向を変えて内側へ戻ることや、外周に沿って進むことは可能です。
- XZ位置だけを制限し、高度は変えません。外部から範囲外へ移動されても次の移動更新で範囲内へ補正します。

SeaBedWorldBorderのInspectorで、範囲のSeaBed、端からの余白、壁の高さ、濃くなる距離、薄くなる距離、遠距離の濃さ、色を調整できます。保存する場合はPlay前に空GameObjectへ同コンポーネントを1つ追加してください。既存があれば自動生成しません。高さとSeaBedの変更はPlayを再実行して反映してください。

壁は軽量な4面のメッシュと共有マテリアル1個です。URP用の専用ShaderをAssets/Resources/Shaders/SeaBedWorldBorder.shaderに置き、ビルドでも含まれる構成にしています。Shaderはカメラから壁面に垂直な方向の距離で濃さを計算します。XY面はZ座標差、YZ面はX座標差を使い、同じ面の全体を同じ濃さにします。追加カメラやVosk/Kinectモデルの再読み込みは行いません。Play終了時に生成メッシュとマテリアルを破棄します。シーン・Prefab・霧設定は保存・変更しません。

SeaBedの範囲が見つからない場合は警告します。Shaderが見つからない場合もエラーを出し、位置制限は維持します。境界はSeaBedの外接矩形で、凹凸のある海岸線をなぞるものではありません。

検証：C#の参照DLLコンパイルと境界数学の14項目のテストを実施。Unityを起動していないため、Shaderの実コンパイル、海中での見え方、実移動の動作は未確認です。


壁の上端は既定でSeaBedの上端＋1,500mです。上下への高さ300mに追加上方向1,200mを加算します。高さを変更したらPlayを再実行してください。
