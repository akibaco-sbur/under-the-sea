# Mainの音源接続

PlayするとDiverAudioを1つ自動生成し、7個の2D AudioSourceで再生します。AudioListenerは追加しません。音源は非同期で1回読み込み、音のたびに読み直しません。

| 音源 | タイミング |
| --- | --- |
| InWater.mp3 | ロボットの起動演出が終わり、操作可能になってから常時ループ |
| Breathv2.mp3 | 同じ体験期間に一定周期で再生。初期値6秒。音源より短い周期を指定した場合は、音源の終了を待つ長さに補正 |
| Feeding.mp3 | 魚が餌を食べたときに1回 |
| Noise_Roop.wav | 画面ノイズが強くなり始めたところからループ。壁に近づくほど音量が上がり、離れると消える |
| PopUp.mp3 | 警告窓が新しく出た瞬間。最大2音の重なりに制限 |
| Recognision.mp3 | Voskの確定結果が登録コマンドに一致したとき。餌やりの手のひら条件で拒否された場合や、餌やりロック中の視点・前進指示は除外 |

開発用キーでも視点・前進・停止・撤退・餌やりの受付音を確認できます。受付音は短時間の連続発火を制限し、重なって音量が増え続けることを防ぎます。認識前画面・起動演出中は再生しません。撤退・離席終了・ボーダーでの自動終了は同じ停止処理を通り、環境ループとノイズをフェードアウト、排気・餌・ポップアップ音を停止します。受付音だけは短い末尾を再生できます。

InspectorのDiverAudioControllerで全体と各音の音量、排気音の周期、音全体のON/OFFを調整できます。保存したい場合はPlay前にMainの空GameObjectへ同コンポーネントを1つ追加して設定してください。音源も直接指定でき、その場合は指定したAudioClipを優先します。

ビルドでも自動取得できるよう、元のAssets/Audioの6ファイルをAssets/Resources/DiverAudioへコピーして使用しています。元のファイルと.metaは変更しません。今後音源を差し替える場合はResources/DiverAudio側も更新するか、保存用DiverAudioControllerの音源欄へAssets/Audioのクリップを割り当ててください。

VoskやKinectを再起動しません。画面ノイズのリセットやシーン破棄では新しいAudioオブジェクトを生成せず、既存の所有者だけを参照します。音源ファイルや音声認識モデルのZIPを再生ごとに展開する処理はありません。

検証：参照DLLによるC#コンパイルと音量・排気周期など10項目の独立テスト。音源コピーは6ファイルのハッシュ一致を確認します。Unityは起動していないため、実際の再生・ループの継ぎ目・音量バランスは未確認です。
