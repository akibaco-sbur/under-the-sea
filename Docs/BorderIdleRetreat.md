# ボーダー停止後の自動撤退

DiverMovementControllerの「World border idle retreat」で設定します。

- 「ボーダー停止後の自動撤退」：ON/OFF。初期値ON。
- 「自動撤退までの秒数」：初期値15秒、最小1秒。Play中の変更も反映します。保存する場合はPlay前に変更してください。

ボーダーが最も近い障害物として自動ブレーキの原因になり、速度がほぼ0になってから計時します。岩だけが原因の停止や、通常の停止操作・初期待機では新しく計時しません。停止位置から5cmを超えて移動すれば取り消します。首の向きの変更や、移動できないまま繰り返す前進指示だけでは取り消しません。

黄色警告に「あと○秒で自動撤退」を表示します。時間切れには既存の撤退要求を1回だけ実行し、移動・餌やり・音声入力の停止、シャットダウン、軌跡表示へ進みます。認識待ち・起動演出・撤退後・コンポーネント無効化では計時しません。

検証：C#の参照DLLコンパイルと計時・設定変更・再移動・一度だけの発火など15項目の独立テストを実施。Unityは起動しておらず、Gameビューでの連携は未確認です。
